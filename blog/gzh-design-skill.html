3周2400星！公众号排版Skill爆了，但光排版不够


> 一款面向公众号的AI排版工具在GitHub上3周狂揽2500+星。我们看了，发现他们只做了最后一步。


发生了什么


7月1日，中文开发者甲木与摸鱼小李在GitHub上发布了一个叫 **gzh-design-skill** 的开源项目。到7月22日，这个项目已经收获了2505个Star和281个Fork。


它做的事情很简单：把Markdown文稿一键转成可以直接粘贴进微信公众号编辑器的HTML。6套主题、双关卡校验——解决的是公众号创作者最痛的一个点：**编辑器排版难用**。


这个项目采用AGPL-3.0许可证，可以安装在Claude Code、Codex、Cursor等AI编程工具上。2500星是什么概念？很多做了两三年的正经开源项目都到不了这个数。


为什么火？三个原因：**痛点真实**（公众号编辑器是出了名的格式杀手）、**时机精准**（AI Coding Skill生态刚起步，先行者红利）、**门槛极低**（一个文件一条命令，不需要学任何东西）。


我们也有这个能力


坦白说，纳杰觅理的管线里早就有这个功能。


`wechat-publish` 脚本的 `parse_article` 模块，做的就是同一件事——把Markdown文章转成公众号可直接发布的HTML。从「著作权法大修」到「携程51亿反垄断」，每篇文章都是这个脚本发的。


但区别不在功能，在格局。


他们做了一个很好的锤子，我们建了一条流水线


| | gzh-design-skill | 纳杰数字员工 |

|------|:--:|:--:|

| Markdown→HTML排版 | ✅ 6主题+双校验 | ✅ 单主题，持续优化 |

| 选题方向 | ❌ | ✅ MarketExpansion Agent |

| 行业调研 | ❌ | ✅ Researcher Agent |

| 文章撰写 | ❌ | ✅ Writer Agent |

| 封面生成 | ❌ | ✅ Visual Agent |

| 质量审核 | ❌ | ✅ QualityGate 六维评分 |

| 全渠道分发 | ❌ | ✅ Outreach 10渠道 |

| SEO/GEO优化 | ❌ | ✅ Promotion + SiteOps |

| 7×24全自动 | ❌ 手动触发 | ✅ Cron凌晨管线 |


gzh-design-skill是一个优秀的工具——但它只解决了一个问题："排版"。


我们的数字员工系统解决的是整条流水线：**今天凌晨选题 → 调研 → 写稿 → 配图 → 审核 → 全平台发布 → SEO优化 → AI收录追踪**。人还没起床，文章已经发好了。


我们该学什么


1. 开源是最好的品牌


2500星不只是GitHub数据——是2500个公众号创作者知道了这个工具。如果我们把`wechat-publish`独立出来开源，署上"纳杰觅理 / 爱普纳杰·觅理·纳杰"，每多一个Star就是一次免费的品牌曝光。


2. 主题即品牌


gzh-design-skill的6套主题是一个很好的产品思路。我们可以做三套品牌主题：


  • **觅理红**（#8B1A1A）——法律分析类文章
  • **爱普纳杰蓝**（#1F4E79）——专利实务类文章
  • **纳杰绿**（#0F766E）——年费管理/数字员工类文章

读者看到配色就知道文章归属——视觉即品牌。


3. 从"工具"到"平台"是最大的护城河


gzh-design-skill好复制。任何有开发能力的团队，一周就能做出功能等价的替代品。


但一条全自动内容管线——8个Agent、30个Cron、凌晨2点跑到早上6点、覆盖从选题到GEO追踪的全流程——这是时间积累出来的壁垒。不是代码壁垒，是系统壁垒。
