# 公众号文章写作规范（完读率友好版）

> 适用：所有产出公众号文章的 agent（agent-siteops 等）
> 目标：让读者「读完」，而不是「点开」。2026 年算法按完读率/分享率/互动率分流量，不看粉丝数。

---

## 硬性标准（违反任何一条都要重写）

### 1. 篇幅：800–1500 字
- **超过 1500 字 = 不合格**，必须砍。
- 概念界定、制度沿革、逐条法条对比——这些是"论文素材"，公众号里**一律删除或压成一句话**。

### 2. 开头 3 段（决定生死，最重要）
开头 3 段必须是：
- **第 1 段：一句话结论**（读者读完能得到什么 / 最核心的判断）
- **第 2 段：一个冲突数字或紧迫感**（"9月1日施行""只剩31天""62%企业做错"）
- **第 3 段：价值承诺 + 内容预告**（"本文给你 3 件事：①…②…③…"）

❌ **禁止**：面包屑导航、日期/分类/作者、`XX是什么`的定义式开头、背景铺垫、逐条引用法条。

### 3. 结构：结论前置，干货先给
- 顺序必须是：**行动指南 / 红线 / FAQ 在前**，概念、依据、逐条对比在后（或删）。
- 读者坚持不到第七部分才看到干货——所以干货必须排第一。
- 概念定义：压成一句话，塞进相关段落，不单独成段、不做"导读"。

### 4. 小标题：利益/数字导向
- ✅ `3 条红线别踩`、`31 天做对 5 件事`、`新规 5 个变化`、`企业现在要做的 3 件事`
- ❌ `一、概念界定`、`二、制度依据`、`三、适用条件`、`四、操作流程`

### 5. 短句 + 排版
- 每段 ≤ 3 行。
- 多用短句，少用长定语、少用"的"字堆叠。
- 能列表/表格就不写大段文字。

---

## 产出前自检清单（逐条过，全过才能交付）

- [ ] 开头 3 段是"结论 + 冲突 + 承诺"，没有导航/定义/背景？
- [ ] 全文 ≤ 1500 字？
- [ ] 没有"一、二、三"学术小标题？
- [ ] 干货（行动/红线/FAQ）排在前 30%，不是埋在最后？
- [ ] 每段 ≤ 3 行？

---

## 标准开头模板（直接套）

```
【第1段·结论】一句话说出读者能得到的最核心结论。

【第2段·冲突】一个数字或时间点制造紧迫感（施行日期 / 窗口期 / 多少人做错）。

【第3段·承诺】本文给你 N 件事：①… ②… ③… 照着做，别踩坑。
```

---

## 参考示例（改写前后对比）

**❌ 改写前（论文式）**：
> 导读：执行异议之诉，是指案外人或申请执行人因对执行标的享有实体权利、与生效执行依据发生冲突时……「执行难」是民商事诉讼最后一公里的痛点……

**✅ 改写后（公众号式）**：
> 打赢官司却拿不到钱？执行异议之诉，就是破解"执行难"的那把钥匙。
>
> 全国法院每年超过 30% 的胜诉判决无法执行到位。你的债权，可能就卡在"案外人异议"这一步。
>
> 本文给你 3 件事：① 15 天提起期限别错过 ② 举证要点 ③ 3 个最常见败诉原因。照着做，别让胜诉判决变成一纸空文。

## 与何律既有风格的关系

本规范是在何律既定写作风格（短句、案例驱动、第一人称、王阳明收尾）之上的**篇幅与结构约束**——风格不变，只加"完读率"硬指标：**开头结论化、篇幅 ≤1500、干货前置、标题利益化**。
